## 4. 给 GPT 的余下契约（仅剩 M3 / M5 / M6）

### 4.1 M2 卡库已交付状态（`public/data/cards.json` & `catalog.json`）

已按契约落盘并通过 `tests/cards.test.mjs`：3.5 MB，27 系列 4,577 张，其中 4,562 张精确附带 52Poké `revision` 与 CC BY-NC-SA 3.0 出处，15 张未建单页的特典卡保留准确官译名与 MIT 兜底说明。`deploy.yml` 每日 02:30 CST 会自动重新执行 `node tools/cards/sync.mjs`。

### 4.2 M3 引擎与 M5 模型契约（`public/battle/`）

1. **`public/battle/runtime.mjs`**：需导出 `export async function instantiateBattle(wasmBytes)`（与 `tests/battle-engine.test.mjs` 保持一致），返回一个同步调用函数 `engine(input)`：
   - `{ op: 'coverage', ids: string[] }` → `{ coverage: { [id]: 'Implemented' | ... } }`
   - `{ op: 'game', deck, enemy, weights, enemy_weights?, seed, first, replay? }` → `{ outcome: 'win'|'loss'|'draw', turns, actions, points, first, replay?: [...] }`
2. **`public/battle/deckgym.wasm`**：由 `engine/pocket_lab.rs` 编译（注意本机无 `cargo`，需装 `rustup target add wasm32-unknown-unknown` 或在 GitHub Actions 里编译）。
3. **`public/battle/models/current.json`**（或 `baseline-v0.json`）：
   ```json
   {
     "version": "baseline-v0",
     "features": 22,
     "weights": [0, 0, ...],
     "trainedGames": 0,
     "eval": { "opponent": "baseline-v0", "games": 0, "wins": 0, "draws": 0, "losses": 0 },
     "createdAt": "2026-11-19T00:00:00Z",
     "engineCommit": "a0f9d14"
   }
   ```
4. 可选优化：`battle.mjs` 目前在主线程分片运行 500 局（每 5 局让出事件循环），若单局耗时超过 15ms，建议再补 `public/battle/worker.mjs` 将循环移入 Web Worker（保持 `runs` IndexedDB 写入契约不变即可）。
