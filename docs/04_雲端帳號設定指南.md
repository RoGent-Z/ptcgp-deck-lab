# Pocket Lab 會員帳號與雲端同步設定指南

Pocket Lab 為純靜態 GitHub Pages 網站（`https://rogent-z.github.io/ptcgp-deck-lab/`），會員註冊、登入與個人牌組／持卡收藏雲端同步採用 **Supabase Auth + Postgres Row Level Security (RLS)**：前端僅使用公開的 `Project URL` 與 `anon public key`，不暴露任何高權限金鑰，每位登入玩家僅能讀寫自己 `auth.uid()` 對應的資料列。

## 啟用步驟（約 3 分鐘）

1. 前往 [Supabase](https://supabase.com/) 建立免費專案。
2. 進入左側 **SQL Editor**，執行倉庫內的 [`supabase/schema.sql`](../supabase/schema.sql) 建立 `public.pocket_lab_vaults` 資料表與 RLS 權限規則。
3. （選配）若希望會員可直接註冊後立刻使用而不需先驗證信箱，可在 **Authentication → Providers → Email** 關閉 `Confirm email`；若需開啟 Google 登入，則在 **Authentication → Providers → Google** 填入 Google OAuth 憑證，並在 **Authentication → URL Configuration** 將下列網址加入 `Redirect URLs`：
   - `https://rogent-z.github.io/ptcgp-deck-lab/`
   - `http://127.0.0.1:4157/`
4. 進入 **Project Settings → API** 複製 `Project URL` 與 `anon` `public` key，寫入 [`public/app/cloud-config.mjs`](../public/app/cloud-config.mjs) 並推送至 `main`，所有訪客即會自動啟用會員註冊與跨裝置同步。
