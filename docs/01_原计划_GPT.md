# Pokémon TCG Pocket 繁中组牌与对战实验室

按你选定的方式，**只部署在 GitHub**。玩家可以查繁中卡牌、保存自己的牌组、查看当前赛事热门构筑，再一键让自己的牌组挑战排名前十的对手，每个对手打 50 局。已核实 GitHub 登录账号为 `RoGent-Z`，计划新建独立公开仓库 `RoGent-Z/ptcgp-deck-lab`，通过 GitHub Pages 提供网站。本轮完成了手册阅读和数据源核查，仓库与网站尚待实施。

## 1. 繁中卡库与本地组牌

- **数据源采用 52Poké 神奇宝贝百科的 Pocket 专区。** 名为 PTCGP Wiki 的站点本次抽查返回 503，其条款要求取得书面许可才能系统取数建库。52Poké 明确允许按规则机器读取，已核实「雙元融合」系列目录和单卡页能对应繁中卡名、招式、效果及异画编号。网站按非商业方式发布，保留来源、修订版本和署名，卡图按各文件授权处理。[PTCGP Wiki 条款](https://pokemon-tcg-pocket.wiki/terms-service) · [52Poké 机器读取守则](https://wiki.52poke.com/zh-hant/神奇宝贝百科:机器读取守则) · [52Poké 版权声明](https://wiki.52poke.com/zh-hant/神奇宝贝百科:版权声明)
- **按原分类浏览。** 保留系列、卡包、卡牌类别、属性、稀有度、进化阶段及来源分类名称。支持用简繁卡名、卡号、招式或效果搜索。异画和再录各保留收藏编号，同名卡张数限制与实际对战效果分别校验。每个系列显示应有张数、已收录张数和缺失明细，方便查漏。[「雙元融合」系列目录](https://wiki.52poke.com/wiki/雙元融合（TCGP）)
- **从查卡直接进入组牌。** 玩家可以记录持有张数，把卡加入草稿，设置能量区，并保存、复制、改名或导入导出多套牌组。用 IndexedDB 在浏览器本地保存。未完成的草稿可以保存，开始对战前检查 20 张、同名最多 2 张、至少 1 张基础宝可梦及当前赛制合法性。[Pocket 组牌规则](https://wiki.52poke.com/zh-hant/对战（TCGP）)

## 2. 当前赛事排行与更新

- **GitHub Actions 每 15 分钟尝试增量同步。** 卡库按 Wiki 要求串行限速，大规模补采安排在北京时间 02:00–07:59。访客点击「检查更新」即可加载最新已发布数据。页面分别显示最近检查时间、最近成功更新时间和数据覆盖范围。源站维护、限流或数据校验失败时，继续提供上一份完整快照。GitHub 的定时任务可能延迟，页面以实际时间为准。
- **热门度来自真实比赛。** 通过 Limitless 公开 API 获取已结束的 Pocket 标准单牌组赛事。统计窗口取「最近 28 天」与「当前版本生效后」的交集。默认按参赛使用率排名，可切换赛事胜率、冠军次数和八强次数，并查看分母及来源赛事。赛制字段缺失时核对赛事详情，轮空和弃权单列，三局两胜的整场比分与单局结果分别统计。
- **前十指使用率最高的十种牌组。** 每种选择实际提交过、20 张牌和能量配置齐全的最常见构筑，同频时优先取名次更高、日期更新的一份。玩家在开测前就能查看这十份完整牌表和比赛出处。若新版本暂时不足十种，显示已有样本及缺口，保留上个版本的报告供查看。

## 3. 对战引擎、机器学习与胜率

- **先校验规则，再训练 AI。** 以开源 Rust 引擎 `deckgym-core` 为基础，编译为浏览器可运行的 WebAssembly。已核实的上游版本自报实现 3,340/3,761 张；实施时按独立卡牌效果核对当前合法卡池，补齐缺项，并以官方规则验证先后手、能量区、进化、状态、击倒计分、平局和双属性。新卡同步后若效果尚待核验，组牌器会指出具体卡号及受影响的模拟。[固定引擎版本](https://github.com/bcollazo/deckgym-core/tree/a0f9d14bf2dd2a342e53cd7057486d7ce96ea545)
- **双方使用同一版训练过的 AI。** 先以规则策略生成示范，再通过自我对弈训练轻量决策模型。模型每一步只接收该玩家能看到的信息和合法行动。使用留出的牌表与随机种子，对固定基准策略做先后手均衡评测。仓库公开训练脚本、模型权重、评测局数和胜平负，便于复现。
- **每次运行固定十套对手、规则版本和模型版本。** 对每个对手先手 25 局、后手 25 局，共 500 局，由浏览器后台线程执行。页面显示进度，支持中断续跑和逐局回放。报告展示每组胜／平／负、先后手表现及 95% 区间。**综合模拟胜率＝总胜局数 ÷ 500**，平局单列。正式报告在 500 局全部有效完成后生成，赛事实际胜率另列供比较。
