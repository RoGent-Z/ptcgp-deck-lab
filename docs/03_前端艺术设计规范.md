# 前端艺术设计规范 · Pocket Lab「瑞士红白灰平面系统」

> 作者：Antigravity，2026-11-19。本文件是前端的**唯一视觉依据**。改动视觉时先改这里，再改 `public/app/site.css`。
> 实现位置：`public/app/site.css`（令牌 + 瑞士网格组件）、`public/app/views.mjs` / `public/app/main.mjs`（视图与交互）、`public/app/cardface.mjs`（实体卡图、`EnergyToken` 原版能量球与宝可梦 2D 像素画解析）。

## 0. 设计判读（Design Read）

**这是一个给 PTCGP 竞技玩家用的“组牌 + 情报 + 模拟”工具站，桌面与手机并重；视觉语言已从早期“夜间牌桌”正式重构为「红白切分背景 + 瑞士国际主义平面网格（Swiss Style）+ 灰阶工程纹理 + 纯原版图素」，严格禁用任何玻璃拟态（No Glassmorphism）。**

| 刻度 | 值 | 含义 |
| --- | --- | --- |
| DESIGN_VARIANCE | 5 | 严格模块化方格网（卡牌 5×4 陈列、指标台账、排行榜）；只有首页 Hero 与牌桌展墙利用不对称切分制造视觉张力 |
| MOTION_INTENSITY | 3 | 保留 115° 卡面镭射扫光、1px 实线边框瞬切、2px 硬阴影位移与点阵入场动画；禁用模糊发光或慢漂浮 |
| VISUAL_DENSITY | 6 | 情报榜单与图鉴紧凑清晰；所有面板严格不透明、高对比可读 |

### 红白切分 + 灰阶纹理设计原则

1. **红白切分背景**：全站底色采用类似精灵球与瑞士海报的**锐利红白水平不对称切分**——上半区为高饱和瑞士信号红（`#d62828`），由 `3–4px` 石墨黑线（`#141414`）一刀切入下半区微灰点阵白底（`#f6f6f4` + `18px` 点距）。
2. **禁止玻璃型 UI**：全站禁止 `backdrop-filter: blur(...)` 与半透明磨砂卡片。顶栏 `.mast`、底栏 `.bottom-nav`、面板 `.panel`、弹框 `dialog` 均为 100% 不透明纯白（`#ffffff`）或雾灰阶（`#f4f4f2` / `#eaeae6` / `#dfdfd9`）材质。
3. **其余纹理优先使用灰色**：陈列墙底垫使用微点阵灰，空卡槽使用 `45°` 斜线制图灰纹，Hero 右侧参数区使用 `45°` 浅灰网格纹，所有实卡高饱和卡图在纯灰阶框架上自然跳脱成绝对主角。

## 4. 核心组件与素材资产

### 4.1 实体卡图 + 垫底数据卡面 `CardFace`

- `63:88` 繁中主图源 `game.pokemontcgpocket.app/zh-tw/tcgp/{SET}/{NUM}/low.webp`（高清弹窗 `/high.webp`），自动降级 Limitless CDN 与浅灰点阵 `.cf-fallback`。
- `ex`、稀有度 `☆` 及以上、`✦`、`AN`、皇冠卡保留 115° 镭射倾斜光效。

### 4.2 原版能量图标 `EnergyToken`（纯图无文字）

- **严禁在能量标记内部绘制「草 / 火 / 水」文字**：全部 11 种属性均使用抓取落盘至 `public/assets/energy/{grass,fire,water,lightning,psychic,fighting,darkness,metal,colorless,dragon,fairy}.png` 的 52Poké 原版球状 TCG 图标（`18px` / `22px` / `28px`）。
- 筛选条中的训练家类别图标统一采用 `public/assets/energy/trainer.png` 原版 2D 像素精灵球。

### 4.3 宝可梦 2D 像素画与卡组 3 代表选定（`PokemonSprites`）

- 全量 1,086 种宝可梦形态（含地区形态、Mega 进化、`Team Rocket's` 前缀、`Origin Forme` 等）经 `tools/assets/sync_sprites.py` 抓取落盘至 `public/assets/pokemon/{slug}.png`（Pokésprite Gen 8 + Limitless R2 Gen 9 / Z-A Mega，Pillow 裁除多余透明边距），浏览器渲染采用 `image-rendering: pixelated` 保持点阵锐利。
- 每个卡组（及草稿、赛事原型、对战对手）在名称旁展示**最多 3 只代表宝可梦 2D 像素画**：
  - 未手动指定时，由 `resolveFeaturedPokemon` 按「ex/Mega → 高阶进化 → 投入张数 → 卡组顺位」自动去重挑选前 3 只；
  - 用户可在 **我的牌组（`#decks`）** 与 **图鉴草稿（`#catalog`）** 下方的「代表宝可梦像素画」选择器中点击切换选定 1–3 只并持久化保存（随 JSON 导入导出同步保留），或一键`恢复自动`。

### 4.4 份额条 `ShareBar` 与 50 格胜负点阵 `GameStrip`

- 使用率份额条使用 `--swiss-red` 实心条与 `--grey-2` 灰槽；胜负偏差条向右 `--win` 绿 / 向左 `--loss` 红。
- 50 格点阵采用 `11×11px` 方格与 `1px` 锐角，未执行局为 `--pending` 中灰格。

## 5. 页面蓝图

### 5.1 首页 `#home`
- **不对称红白切分 Hero**：左栏信号红 `#d62828` 主标题与白/黑双 CTA；右栏斜纹灰 `当前使用率前三` 面板实时陈列前 3 名原型及其 3 只代表像素画。
- 下接 4 列白灰交替统计台账、**当前前十对手（带能量球 + 3 只代表像素画）**、若已有置顶牌组则在中部展示 **我的牌桌陈列（10×2 迷你实卡展条 + 标题像素画）**，底部为 3 栏不等宽快捷入口。

### 5.2 卡牌圖鑑 `#catalog`（草稿編輯唯一排序與代表設定入口）
- 左列：`卡牌圖鑑` 頁頭 + 純原版能量球與精靈球屬性篩選條 + 級聯下拉篩選（選定 `訓練家` 或點亮精靈球時自動切換為 `#filter-subtype` 子類選單：`物品` / `支援者` / `寶可夢道具` / `競技場（場地）` / `化石`，並與寶可夢屬性互斥）+ 5 列（平板 3 / 手機 2）實卡網格。
- 右列（桌面固定 / 手機抽屜）：**目前草稿** —— 頭部展示代表像素畫、`預設排序`、`完整預覽` 與 `X/20` 計數，包含 34×34px 正方瑞士框能量區選擇、`代表寶可夢 X/3` 編輯條，以及支援 `▲`/`▼` 按鍵與拖曳調整的草稿清單（未自訂時依 PTCGP 預設順序：寶可夢屬性輪＋進化鏈同組相鄰 → 物品 → 化石 → 寶可夢道具 → 支援者 → 競技場）。

### 5.3 我的牌組 `#decks`（唯讀鎖定展示）
- 左列：已儲存牌組列表，每條均在名稱旁唯讀渲染最多 3 隻代表寶可夢 2D 像素畫與首頁陳列標籤。
- 右列：預設 `完整陳列 (5×4)`（灰點陣展牆襯底、斜紋灰空位），支援切換 `精簡清單`、`#deck-rename-input` 行內改名、`沉浸大螢幕預覽`、`設為首頁陳列`；無代表寶可夢編輯器與排序按鈕，嚴格鎖定儲存時的牌組順序，僅可經由 `載入至草稿編輯` 回圖鑑修改。

### 5.4 賽事環境 `#meta` & 對戰測試 `#battle` & 資料來源 `#sources`
- 所有原型行、代表牌表彈窗、10 個鎖定對手清單與戰報行均統一使用台灣繁體中文與翻譯後牌組名稱，並以固定寬度能量槽位（40px / 窄屏 34px）與精靈槽位對齊所有列表的像素畫與標題欄；`#home` 前十卡片名稱固定獨立成行。

## 6. 响应式与移动端防溢出铁律

- 断点：`>= 1280` · `1024–1279` · `768–1023` · `< 768`（顶栏保字标与检查更新，不透明纯白底导航移至底部 60px + 安全区）。
- 所有单列或卡片列表 Grid 容器统一使用 `grid-template-columns: minmax(0, 1fr)` 并为 Flex/Grid 子项配置 `min-width: 0`，确保 `390×844` 窄屏下长卡组名正确省略截断、输入框不与视图切换条挤压重叠、零横向溢出。
